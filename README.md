# tanks
### Репродукция игры "Танчики" на TypeScript.

Для игры необходимо скачать папку **/dist** и запустить в ней файл **index.html**.

В директории **/src** расположены исходники, из которых компилируется файл **/dist/bundle.js**. Для самой игры данная директория не нужна.

### Управление

**В меню**

Выбор пункта меню: up/down

Выбор уровня: left/right

Применение: Enter

**Первый игрок**

Перемещение: wasd

Стрельба: Space

**Второй игрок**

Перемещение: okl;

Стрельба: Enter
